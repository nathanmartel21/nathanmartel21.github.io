Configuration (une seule fois)

L’app tourne entièrement dans ton navigateur : il lui faut ta propre clé API Strava. Ça prend deux minutes :

  1. Va sur strava.com/settings/api (connecté avec ton compte nathan.martel@sfr.fr) et crée une application.
  2. Renseigne Site web : https://nathanmartel21.github.io et Domaine de rappel autorisé : nathanmartel21.github.io.
  3. Copie le Client ID et le Client Secret ci-dessous.

🔒 Tes clés et tes données restent dans le localStorage de ce navigateur : rien n’est envoyé ailleurs que vers l’API Strava. Ne partage pas ton Client Secret.

Importer un export (Strava ou Garmin)

Gratuit, sans abonnement. Dépose le fichier .csv d’export de tes activités — l’app détecte automatiquement le format Strava ou Garmin.

📦 Depuis Garmin Connect
  1. Sur Garmin Connect → Activités, fais défiler pour charger toutes les activités voulues (ou filtre par période).
  2. Clique sur l’icône d’export « Exporter au format CSV » en haut à droite de la liste.
  3. Nomme le profil et dépose le CSV ci-dessous.
🟠 Depuis Strava
  1. Paramètres → Mon compte → « Télécharger ou supprimer mon compte » → Demander mon archive. Tu reçois un ZIP par e-mail (ça peut prendre quelques heures).
  2. Décompresse et récupère activities.csv à la racine.

🔄 Pour « synchroniser » plus tard : réexporte et réimporte dans le même profil — seules les nouvelles courses s’ajoutent.
