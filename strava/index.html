Configuration (une seule fois)

L’app tourne entièrement dans ton navigateur : il lui faut ta propre clé API Strava. Ça prend deux minutes :

  1. Va sur strava.com/settings/api (connecté avec ton compte nathan.martel@sfr.fr) et crée une application.
  2. Renseigne Site web : https://nathanmartel21.github.io et Domaine de rappel autorisé : nathanmartel21.github.io.
  3. Copie le Client ID et le Client Secret ci-dessous.

🔒 Tes clés et tes données restent dans le localStorage de ce navigateur : rien n’est envoyé ailleurs que vers l’API Strava. Ne partage pas ton Client Secret.
