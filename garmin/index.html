Importer un export local

Gratuit, sans serveur. Lance python garmin/server/export_local.py sur ta machine, puis dépose le garmin-data.json obtenu.

⌚ Comment générer le fichier
  1. cd garmin/server && pip install -r requirements.txt
  2. python export_local.py --days 120 (te demande tes identifiants Garmin, en local uniquement).
  3. Dépose le garmin-data.json créé ci-dessous.

🔄 Pour « synchroniser » : relance le script et réimporte dans le même profil — seules les nouvelles données s'ajoutent.
